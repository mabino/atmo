# Atmo 1.6.0

Atmo 1.6 adds a device Get Info window and smarter install-location detection.

## New

- **Get Info** — press Command-I (or choose File > Get Info) to open a window with full details about the selected device: model, IP address, identifiers, pairing status, power state, and per-protocol pairing and credential information. The window updates live as you switch devices.

## Improved

- **Install-location check** — Atmo no longer asks you to move it to Applications when it is already in /Applications or ~/Applications, including on first launch of a freshly downloaded copy (when macOS runs the app from a temporary Gatekeeper location)

## Notes

- Atmo now requires macOS 14 (Sonoma) or later
